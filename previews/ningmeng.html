这是一段用于展示柠檬模版的正文段落。柠檬的核心识别是 h2 高亮笔块 —— 把 h2 实心填充成 accent 色，配 paper 色文字，像海报上的分类标签，最远也能一眼分出层级。其它元素保持克制，让 h2 是页面唯一的"亮点"。

这套模版适合需要强视觉钩子的公众号头条、产品发布会推送、活动海报型长文。点这里看更多示例。

一、模版要解决的问题

每个模版都要回答两个问题：这套排版的"独特动作"是什么，以及它适合什么场景。如果两者都说不清，模版就没存在必要。

1.1 节奏与呼吸

  • 正文行距 1.9，段间距 20px，留白多一档
  • 列表用 accent 实心圆点 bullet，强化视觉锚点
  • 强调统一走 accent 色 —— 不是粗体，是颜色 + 粗体

1.2 装饰原则

  1. 每个模版只有一个签名装饰，不堆砌
  2. 柠檬的签名是 h2 实心块 —— 其它地方收敛
  3. 能用排印手法的，绝不上图标和渐变

设计模版不是堆装饰元素，是给读者一个"层级地图"。

—— 一个版式克制者的呓语

1.3 代码块呢？

代码块保留之前的 terminal-dark，因为它已经够好了，没必要每个模版重新设计。行内代码 inline code 在柠檬里用反白色块。

function buildTemplate(id) {
  // 柠檬：实心 accent 块就是签名
  return { id, signature: 'h2 highlight block' };
}

三、下一步

如果这个方向 OK，剩余 5 个新模版（重影 / 海桐 / 靛青 / 金石 / 月白）都会按这个密度推进 —— 每个一个识别度强但克制的签名装饰，加适配公众号粘贴的真实 DOM 镜像。

验收要点

  • 是否够"精美"，不是花
  • 是否够"识别"，远看能区分
  • 是否能落到公众号 inline 后形不变
