这是一段用于展示 10 套版式 的正文段落。每个模版有一个清晰的视觉签名，远看就能区分；近看克制不堆装饰。点上方任意标签切换看效果。

这套工具的目标是：让 Markdown 写完，一键复制到公众号 / 飞书 / Notion。版式的"signature 动作"会保留到目标平台，不会因为粘贴丢失。

一、模版要解决的问题

每个版式都要回答两个问题：它的独特动作是什么，以及它适合什么场景。如果两个问题都说不清，模版就没存在必要。

1.1 节奏与呼吸

  • 正文行距统一在 1.85 - 2.0 区间，让长段落不憋
  • 段间距 16-20px，章节间距 40-56px，建立清晰节奏
  • 每个模版选用一种 accent 色应用方式 —— 不堆叠

1.2 装饰原则

  1. 每个模版只有一个签名装饰，其它地方收敛
  2. 能用排印手法的，绝不上图标和渐变
  3. 装饰必须能在公众号粘贴后形不变

设计模版不是堆装饰元素，是给读者一个"层级地图"。

—— 一个版式洁癖者的呓语

1.3 代码也要好看

代码块统一保留 terminal-dark，跨模版一致。行内 inline code 在每个模版有不同处理 —— 有的反白，有的下划线，有的方框。

function applyTemplate(id, root, ctx) {
  // 每个模版只做一件事：在 inline 复制时
  // 把 ::before / counter() 等 CSS 装饰
  // 替换成真实 DOM，让公众号能保留
  return decorations[id](root, ctx);
}

三、看到这里就够了

每个模版都跟朱砂、青墨、墨黑、茉蓝、栗原 5 套配色正交，跟 霞鹜文楷、思源宋、楷体、苹方 4 套字体也正交。也就是说 10 × 5 × 4 × 2 = 400 种皮肤组合。

下一步要不要做

  • 把模版选择器做成更精致的卡片选择器
  • 每个模版的公众号 inline 镜像做 case 测试
  • 加 AI 起稿（用户自带 Key）
