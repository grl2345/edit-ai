关于 Markdown AI

让中文 Markdown 排版好看一点，再好看一点

这是什么

Markdown AI 是一款专为中文写作者打造的在线 Markdown 渲染与排版工具。打开浏览器即用，无需安装，所有数据保存在本机。它的设计目标只有一个： 让你写出的中文 Markdown，直接复制到公众号、知乎、飞书、Notion 时，效果就已经很好看。

核心功能

  • 实时渲染：左编辑右预览，所见即所得；
  • 中文字体排版：内置霞鹜文楷 TC、思源宋体、JetBrains Mono 等组合，行距字距按中文阅读习惯调整；
  • 多套排版模板：宠英、格栅、海报、红榜、画报、节刊、激光、卷首、柠檬、清叶、手札、印章、月报、樟叶等十余种风格；
  • 代码语法高亮：基于 highlight.js，支持上百种语言；
  • 一键复制富文本：直接粘贴到微信公众号 / 飞书 / Notion，样式不丢；
  • 知乎 & Twitter 适配：知乎按其编辑器特性做了 HTML 适配，Twitter 自动拆条；
  • 导出独立 HTML：样式内嵌，单文件即可双击打开；
  • 深色 / 浅色主题：跟随系统或手动切换；
  • AI 美化（可选）：自行接入 OpenAI / Anthropic / DeepSeek 等大模型，对文档进行排版优化、错字润色；
  • 纯前端、零上传：文档、图片、AI 密钥都只在你的浏览器里。

设计理念

市面上的 Markdown 编辑器大多面向英文场景，对中文的字号、行高、段距、标点挤压、引号样式都不够考究。Markdown AI 从配色与字体开始重做：朱砂红 #c44b2b 作为强调色，米色纸面 #f6f3ed 作为底色，提供长时间阅读的舒适度；衬线中文字体（霞鹜文楷）让正文读起来像一本认真排过的书，而不是一段冷冰冰的纯文本。

我们相信：写作工具应该让人想打开它，而不是只是"能用就行"。

技术栈

  • 构建：Vite + React 18 + TypeScript
  • Markdown 解析：marked + marked-highlight
  • 代码高亮：highlight.js
  • 本地存储：localStorage + IndexedDB（用于图片缓存）
  • 部署：静态托管，任意 CDN 可跑

路线图（部分）

  • 更多平台适配（小红书图文、即刻、Substack）；
  • "灵感库"——开放更多中文排版风格供一键套用；
  • 本地 PDF 高保真导出；
  • "写作教程"专栏——把这些年踩过的中文排版坑系统整理出来。
